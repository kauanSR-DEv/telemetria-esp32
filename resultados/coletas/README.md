# Coletas experimentais

As pastas de rodada serão criadas aqui pelo coletor. O nome inclui data, hora, técnica, modo e semente. Exemplo de **padrão de nome**, sem dados fictícios: `AAAAMMDD_HHMMSS_micros_SUM_M1_seed1/`.

Cada pasta contém `tx.txt`, `rx.txt`, `noise.txt`, CSVs, resumo e informações da sessão. Consulte [o guia de coleta](../../docs/coleta.md).

Rodadas de diagnóstico, interrompidas ou inválidas também ficam preservadas, mas não entram nas tabelas finais.
